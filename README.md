# Beauty Dynastya 2.0

Полный сайт международного онлайн-чемпионата, перенесённый со статических HTML-страниц на React 19, TypeScript, Vite и Tailwind CSS 4. Оригинальные тексты, 37 судей, 5 спикеров, 3 участника и партнёр сохранены.

Сайт: **https://snikasipoin.github.io/beauty-dynastya-2.0/**

## Локальный запуск

Требуется Node.js 24 и pnpm 11.25.0.

```sh
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm dev
```

Vite напечатает адрес локального сервера. Для проверки production-сборки:

```sh
pnpm build
pnpm preview
```

Production preview доступен по адресу `http://localhost:4173/beauty-dynastya-2.0/`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` автоматически проверяет, собирает и публикует сайт после каждого push в `main`. Он выполняет линтер, 45 браузерных тестов, TypeScript-проверку и production-сборку.

В Settings → Pages источником публикации должен быть **GitHub Actions**. Публикуется только каталог `dist`, исходники и архив исходного сайта в него не входят. Запустить публикацию вручную можно в Actions → Deploy Beauty Dynastya to GitHub Pages → Run workflow.

`vite.config.ts` задаёт `base: '/beauty-dynastya-2.0/'` для сборки и production preview. Если имя репозитория изменится, измените `base`. JS, CSS, изображения и шрифты из `src` получают хэши при сборке; ручные `?v=3` не нужны.

## Форма Web3Forms

Без рабочего ключа форма проверяет поля и предлагает отправить заявку через официальный Telegram. Она **не показывает ложное сообщение об успешной отправке**.

Для настоящей отправки:

1. Создайте ключ получателя на https://web3forms.com для почты организатора.
2. Откройте репозиторий → Settings → Secrets and variables → Actions → Variables.
3. Создайте Repository variable `VITE_WEB3FORMS_ACCESS_KEY` с полученным значением.
4. Повторно запустите workflow публикации: значение встраивается во время сборки.

Для локальной разработки скопируйте `.env.example` в `.env.local` и укажите ключ. Перезапустите Vite. Web3Forms access key — публичный ключ получателя, он доступен браузеру; обычные секретные API-токены в `VITE_*` помещать нельзя.

Форма управляется React-состоянием, валидирует имя, страну и роль, блокирует повторную отправку, ограничивает ожидание API и сохраняет данные при ошибке. Все автоматические тесты подменяют API: настоящие заявки при тестировании не отправляются.

## Языки и контент

Поддерживаются EN, RU, IT, DE, FR. Переводы в `src/locales/*.json`, язык переключается без перезагрузки, сохраняется в браузере и в параметре URL `?lang=ru`. JSON-файлы загружаются отдельными хэшированными чанками. При смене языка обновляются заголовок страницы, описание и `html.lang`.

- `src/data/judges.ts` — единый строго типизированный массив судей.
- `src/data/speakers.ts`, `participants.ts`, `partners.ts` — остальные карточки.
- `src/data/championship.ts` — номинации, фильтры и официальные ссылки.
- `src/types/championship.ts` — типы сущностей и допустимых категорий.
- `src/components/` — самостоятельные переиспользуемые разделы.
- `src/assets/` — локальные изображения и шрифты, включаемые в сборку.
- `src/styles/globals.css` — Tailwind, дизайн-токены и общие классы компонентов.

Для добавления судьи добавьте WebP-постер в `src/assets/images/posters/`, запись в массив `judges` и переводы биографии, страны и роли во все пять JSON. Количество судей и стран вычисляется автоматически. Номинация SMP и специализация lamination намеренно находятся в разных справочниках.

Оригинальные страницы сохранены в `beauty-dynastya-main/` как архив. `scripts/migrate-content.py` воспроизводит первоначальное извлечение текстов; не запускайте его поверх дальнейших ручных изменений данных без проверки diff. Для обычной сборки Python не нужен.

## Анимации и доступность

GSAP, ScrollTrigger и useGSAP регистрируются в `src/lib/gsap.ts`. Анимации ограничены компонентом и очищаются при размонтировании, изменении фильтра и языка. `prefers-reduced-motion` отменяет pinning и scrub, возвращая исходные видимые состояния. Навигация и форма работают с клавиатурой, изображения имеют текстовые альтернативы и отложенную загрузку.

## Проверки

```sh
pnpm lint
pnpm build
pnpm test:e2e
```

На Windows тесты используют установленный Microsoft Edge. На Linux/macOS предварительно установите Chromium:

```sh
pnpm exec playwright install --with-deps chromium
```

Тесты покрывают пять языков на ширинах 320, 390, 768, 1024, 1280, 1440, 1920 и 3840 px; фильтры; мобильное меню; форму; сетевую ошибку и успешный ответ API; очистку анимаций при reduced motion. GitHub Actions запускает те же тесты в Chromium на Ubuntu.

## Дизайн и инструменты разработки

`PRODUCT.md` описывает продукт и ограничения, `DESIGN.md` — визуальную систему. Локальные навыки gpt-taste и Impeccable используются при разработке и не входят в браузерный бандл или Git-репозиторий. Результат механического аудита Impeccable: замечаний в компонентах, хуках и стилях не найдено. Визуальный аудит дополняет браузерные проверки.

Satoshi: Indian Type Foundry / [Fontshare](https://www.fontshare.com/fonts/satoshi). Manrope: [Fontsource](https://fontsource.org/fonts/manrope), OFL-1.1. Логотип и постеры перенесены из предоставленного исходного проекта.
