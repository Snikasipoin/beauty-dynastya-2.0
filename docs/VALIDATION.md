# Проверка миграции Beauty Dynastya

## Подтверждённые проверки

- TypeScript strict + production-сборка Vite: успешно.
- Oxlint для src/ и vite.config.ts: без замечаний.
- 45 Playwright-тестов в Microsoft Edge на Windows: успешно.
- Пять языков, восемь ширин: 320, 390, 768, 1024, 1280, 1440, 1920, 3840 px.
- Нет горизонтального переполнения у видимых элементов разделов, header и footer.
- В каждом языке отображаются 37 судей, 5 спикеров и 3 участника; набор ключей переводов совпадает.
- Категории фильтра: lash 21, pmu 7, brows 2, lamination 1, nails 5, hair 1; all 37.
- Переключение языка сохраняет активный фильтр; перезагрузка сохраняет язык.
- Проверены обязательные поля формы, локализация ошибок, HTTP500, повторная отправка и успешный ответ. Внешний API подменён, реальные заявки не отправлялись.
- Проверены клавиатурное закрытие меню через Escape и закрытие после выбора раздела.
- При reduced motion GSAP возвращает исходные стили и удаляет ScrollTrigger; повторная смена языка не дублирует триггеры.
- Отдельный production smoke по /beauty-dynastya-2.0/: все изображения загружены, нет JS-ошибок и HTTP404, отсутствие ключа формы корректно переводит к Telegram.
- Механический Impeccable detect по компонентам, хукам и стилям вернул пустой список замечаний.

## Границы проверки

Независимый finish-reviewer Impeccable дал два замечания к карточкам: биографии должны быть видны сразу, имя должно предшествовать стране. Оба исправлены; повторный verdict pass подтвердил resolved для обоих и disposition: ship в пределах этих исправлений.

Ширины экрана проверялись эмуляцией viewport, а не на физических устройствах. В CI те же сценарии запускаются в Chromium на Ubuntu. Это не сертификат полного соответствия WCAG.

URL-сканер самого Impeccable не завершился из-за ошибки CDP connection closed. Поэтому аудит исходников Impeccable дополнен отдельными браузерными тестами и просмотром production-скриншотов.

Доставка настоящего письма Web3Forms не проверена: ключ организатора в исходном проекте отсутствовал. В рабочей публикации до добавления Repository variable VITE_WEB3FORMS_ACCESS_KEY используется явное сообщение о временной недоступности формы и официальный Telegram.

## Оптимизация ресурсов

Постеры преобразованы из JPEG в WebP: 5 901 604 → 4 873 886 байт (около 17% экономии). Карточки используют loading=lazy и decoding=async. Шрифты локальные, перевод каждого языка вынесен в отдельный чанк; файлы src/assets получают хэши Vite.

## Визуальные доказательства

Локальные снимки для desktop1440 и mobile390, состояний формы и каталога сохранены в .impeccable/review/ и не включены в Git. Длинные fullpage-снимки собраны из последовательных реальных viewport-срезов: стандартный fullPage в Edge повторял область compositor после большой высоты. Во время двух полных снимков sticky-header временно переведён в static; отдельные viewport-снимки отражают его настоящее поведение.
